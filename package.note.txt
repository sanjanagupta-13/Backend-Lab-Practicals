1)what is package.json?
package.json is a special file that describes your node.js project. 

it contains information about your app,such as name,version,script,version...

this file is essential file for managing and sharing node.js  projects,when useing when npm . 

dependency management:

dependencies:list of package reqired for the application to run in production.

devdependencies:list of packages needed only during development &testing.
